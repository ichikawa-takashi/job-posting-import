# 別のパソコンへ移行する

**フォルダのコピーだけでは足りません。** あと3つあります。

---

## 全体像

| | 何が必要か | どこにあるか |
|---|---|---|
| ① | 求人票フォルダ | このフォルダ。丸ごとコピー |
| ② | Claude デスクトップアプリ | 新PCにインストールしてログイン |
| ③ | スキル（求人票を作るルール） | Claudeアカウントに紐づく。同じアカウントなら自動で付いてくる |
| ④ | Cowork でのフォルダ選択 | PCごとの設定。新PCで選び直す |

**サーバー側は何もしなくて大丈夫です。** 求人票のデータはサーバーにあるので、
どのPCから操作しても同じものが見えます。

---

## 手順

### 1. フォルダをコピーする

`求人票` フォルダを丸ごと、新しいPCの「書類（Documents）」に置きます。

**転送方法によって注意点があります。**

| 方法 | 注意 |
|---|---|
| AirDrop・外付けディスク | そのままでOK。おすすめ |
| zipに圧縮して送る | 展開後に `push.command` の実行権限が外れることがあります（下記④へ） |
| クラウド（Drive・Dropbox） | 同期完了を待ってから使ってください。同期中は中身が欠けます |

`json/_sent/` と `pdf/` は隠しフォルダではありませんが、**必ず一緒に持っていってください。**

- `json/_sent/` … 過去に作った求人票のデータ。AIが文章のトーンを揃えるときの見本
- `pdf/` … 元の求人票PDF。処理済みかどうかの判定にも使っています

### 2. Claude デスクトップアプリを入れてログインする

**同じアカウントでログインしてください。** スキル（`job-posting-import`）は
アカウントに保存されているので、ログインすればそのまま使えます。
別アカウントの場合は、スキルを入れ直す必要があります。

チャットで `/job-posting-import` と打って反応すれば、スキルは入っています。

### 3. Cowork でフォルダを選ぶ

「フォルダを選択」から、コピーした `求人票` フォルダを指定します。
これはPCごとの設定なので、新PCでも必ず必要です。

### 4. push.command を使えるようにする

新しいPCでは、初回だけ2つの作業が必要です。

**① macOS の警告を許可する**

ダブルクリックすると「開発元が未確認のため開けません」と出ます。

```
右クリック →「開く」→ もう一度「開く」
```

**② 実行権限が外れていたら戻す**

zipで転送した場合、ダブルクリックしても何も起きないことがあります。
ターミナルで次を実行してください。

```bash
chmod +x ~/Documents/求人票/push.command
```

### 5. 動作を確かめる

`push.command` をダブルクリックします。

```
json フォルダに送るJSONがありません。
（送信済みのものは json/_sent/ に移動しています）
```

これが出れば正常です。サーバーと通信できています。

## つまずきやすいところ

### 「必要なコマンドが見つかりません: python3」と出る

新しいMacには python3 が入っていないことがあります。
ターミナルで次を実行し、案内に従ってインストールしてください。

```bash
xcode-select --install
```

数分で終わります。インストール後、もう一度ダブルクリックしてください。

### ダブルクリックしても何も起きない

実行権限が外れています。上の手順4-②を実行してください。

### 「認証に失敗しました」と出る

`push.command` の中のトークンが古いか、サーバー側で無効化されています。
`public/admin/config.php` の `API_TOKENS` に、そのトークンが載っているか確認してください。

### 日本語のファイル名が文字化けする

Mac同士なら通常は起きません。Windowsを経由した場合に起きることがあります。
その場合は、`pdf/` の中のファイル名を手で直すか、元のPDFを入れ直してください。

## 旧PCの後片付け

**`push.command` にはあなた専用の送信キーが入っています。**

旧PCを他の人に渡す・処分する場合は、`求人票` フォルダごと削除してください。
念のためキーを無効にしたい場合は、サーバーの `public/admin/config.php` で
`API_TOKENS` の該当行を消して、新しいキーを発行し直します。

---

## 2台で併用する場合

同じフォルダを2台に置いて使うこともできますが、**`json/_sent/` がずれます。**

片方で送信すると、そのPCの `json/_sent/` にだけ記録が残ります。
もう片方は「まだ送っていない」と判断して、同じ求人を二重に送ろうとします。
サーバー側では上書きになるので実害は小さいですが、確認画面の表示が
「新規」になるなど分かりにくくなります。

2台で使うなら、フォルダをクラウド同期に置くか、
**作業するPCを1台に決めておく**のが安全です。
