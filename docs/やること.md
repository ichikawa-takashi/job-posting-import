## 新しいログイン情報（2026-08-17）

| | ID | パスワード | できること |
|---|---|---|---|
| **管理者** | `hreed-admin` | `（伏せています）` | 管理画面で編集・公開。一覧では限定公開と非公開も見える |
| 一覧のみ | `admin` | `（伏せています）`（変更なし） | 一覧ページを見るだけ。管理画面には入れない |

管理者のパスワードは、管理画面の「パスワード変更」でいつでも変えられます。
`config.php` の該当する `'pass' =>` の行を貼り替えるだけです。

**公開状態は3種類になりました。**

| 表示 | 一覧に出るか | ページが開くか |
|---|---|---|
| 公開中 | 全員に出る | 開く |
| 限定公開 | 管理者にだけ出る | 開く（URLを知っている人は誰でも） |
| 非公開 | 管理者にだけ出る | 開かない（管理者だけ確認できる） |

以前の「下書き」は**限定公開**という名前に変わりました。保存されている値
（`draft`）は同じなので、いまある求人の状態は変わりません。

## A. サーバーへアップロード（最優先）

FTPで `public/` の中身を上書きします。**この4つは必須です。**

- [ ] `public/api/import.php`
      公開中の求人が下書きに戻らないようにする修正。成約フィーを守る処理。
      送信前の下調べ用エンドポイント（`?ids=1`）。トークンの複数人対応。
      **`?ids=1&full=1` で本文も返すようにしました。**
      これを上げてから `push.command` を1回動かすと、`json/_server.json` に
      いまサーバーにある求人票の中身がまるごと入ります。
      他の人が追加した求人を私が直すには、これが必要です。
- [ ] `public/admin/config.php`
      **`USERS`（IDと権限）に差し替え。** `API_TOKENS` と `PRESERVE_ON_IMPORT`。
      **アップ前に `member2` を実際のお名前に変えてください。**
- [ ] `public/admin/lib.php`
      権限の判定（`is_editor`）と、公開状態3種類の判定。
- [ ] `public/admin/api.php`
      閲覧者からの操作を拒否。公開状態を3値で受ける。
- [ ] `public/admin/index.php`
      権限が足りないときの画面。公開状態の選択（3択）。
- [ ] `public/admin/admin.js` / `public/admin/admin.css`
      公開状態の3択と色分け。成約フィーの入力欄。
- [ ] `public/list.php`
      権限による出し分け。限定公開・非公開のしるし。**ログイン必須化。**
- [ ] `public/terms.php`  ← **新規ファイル**
      求人票で「施工管理」を「不動産事務」に言い換える表。
- [ ] `public/job.php`
      非公開を404にする処理。言い換えの適用。
- [ ] `public/theme.css` / `public/render.php` / `public/pw-toggle.js`

キャッシュ番号は `?v=20` に上げています。

### 確認

**権限**

- [ ] `admin` / `（伏せています）` でログイン → 一覧は見える
- [ ] その状態で管理画面を開く → 「この画面は使えません」と出る
- [ ] `hreed-admin` でログイン → 管理画面に入れる
- [ ] 管理画面のヘッダーにログイン中のIDが出ているか

**公開状態**

- [ ] 求人を1件「非公開」にする
- [ ] `admin` でログインして一覧を見る → その求人が消えている
- [ ] `admin` のままURLを直接開く → 「ページが見つかりません」
- [ ] `hreed-admin` で同じURLを開く → 黒い帯つきで開ける
- [ ] 求人を「限定公開」にする → `admin` の一覧には出ないが、URLでは開ける
- [ ] 「公開中」に戻す → `admin` の一覧に戻る

**これまでの分**

- [ ] 一覧ページを未ログインで開くとログイン画面が出るか
- [ ] 管理画面に「成約フィー」のセクションが出るか
- [ ] 求人票を1件開いて、フィーがどこにも出ていないか（HTMLソースも）
- [ ] 求人票に「施工管理」が出ていないか（ブラウザの検索で確認）
- [ ] 一覧ページのカテゴリと管理画面の職種名は「施工管理」のままか
